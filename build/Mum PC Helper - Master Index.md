SCRIPT DOCS — RUN ONLY IF NEEDED
Canonical script files live in `scripts/` (and in the release pack under `04 Scripts/`).
Use this order every time:

1. DiskSpaceAudit.ps1 — always first
2. DownloadsAudit.ps1 — usual second step
3. LargeFilesFinder.ps1 — only if space is still tight or unexplained
4. InstalledProgramsExport.ps1 — only if apps review is needed
5. StartupItemsReview.ps1 — only if startup is still slow

BEST DEFAULT VISIT FLOW
1. Open Quick Run Card
2. Ask Mum the opening questions
3. Run DiskSpaceAudit.ps1
4. Run DownloadsAudit.ps1
5. Clean obvious junk from Downloads
6. Tidy obvious Desktop clutter
7. Empty Recycle Bin
8. Recheck free space
9. Update Session Notes
10. Only then decide if LargeFilesFinder, apps review, or startup review is needed


FAST RULES
- use built-in tools first
- audit first
- obvious junk only
- if unsure, leave it and note it
- do not touch system folders
- do not uninstall casually
- do not duplicate docs
