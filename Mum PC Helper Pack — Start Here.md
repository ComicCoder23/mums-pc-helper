MUM PC HELPER — PACK START HERE


Purpose
This pack is for working on Mum’s PC in a simple, controlled way without duplicating work or overbuilding the system.


Main rule
Use the existing docs only.
Do not create extra versions unless something is genuinely missing.
Canonical product name: Mum PC Helper.


Working order
1. Open Mum PC Helper - Master Index
2. Open Mum PC Helper - Quick Run Card
3. Open Mum PC Helper - First Visit Checklist
4. Ask the questions in Mum PC Helper - What To Ask Mum
5. Read Mum PC Helper - Safety Notes before changing anything
6. Run DiskSpaceAudit.ps1 then DownloadsAudit.ps1 if needed
7. Clean obvious junk only, then write Session Notes
8. Only then decide on LargeFilesFinder, apps review, or startup review


What this pack is for
- checking what is slowing the PC down
- cleaning obvious junk safely
- organising the visit in the right order
- keeping clear notes of what was moved, deleted, or left alone


What not to do
- do not delete lots of files in one go
- do not remove anything you are unsure about
- do not install lots of utilities unless the built-in Windows tools are not enough
- do not make duplicate copies of the same instructions
- do not rename the product away from Mum PC Helper in v1


Session principle
Simple first:
- check access
- ask what the problem is
- audit disk space and Downloads
- clean Downloads first
- then Desktop
- then review Documents/Pictures/Videos only if needed
- empty Recycle Bin last


Core docs in this pack
- Mum PC Helper - Master Index
- Mum PC Helper - Quick Run Card
- Mum PC Helper - First Visit Checklist
- Mum PC Helper - Cleanup Order
- Mum PC Helper - What To Ask Mum
- Mum PC Helper - Session Notes
- Mum PC Helper - Safety Notes
- Mum PC Helper - Run Order for Scripts


What to record during the visit
- what feels slow
- what scripts were run
- what was deleted
- what was moved
- what still needs checked later
- any program that looks suspicious, unused, or confusing


End goal
Leave the PC clearer, lighter, and easier to use, while keeping a record of what was done.
